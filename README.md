## Overview
This repository contains my ground-up implementations of neural networks in PyTorch. The architectural progression and theoretical foundation are based on Andrej Karpathy's exceptional [Neural Networks: Zero to Hero](https://www.youtube.com/watch?v=VMj-3S1tku0&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ) series. 

While the curriculum design and core concepts are credited to Karpathy, the code within this repository represents my independent replication and serves as an applied demonstration of my proficiency with PyTorch internals, tensor operations, and custom training loops.
